# Управление доской

Обычная прокрутка перемещает доску по двум осям. Shift + вертикальное колесо перемещает горизонтально; уже преобразованный браузером deltaX повторно не прибавляется. Alt не включает зум. Cmd/Ctrl + колесо и pinch масштабируют вокруг указателя; Safari GestureEvent использует центр жеста, а при отсутствующих координатах — центр доступной доски. Диапазон — 8–250%. Вертикальный переключатель содержит +, текущий процент и −. Кнопки +/− используют центр доступной доски. Кнопки «100%» и «Вся схема» удалены из интерфейса.

Space + левая кнопка и средняя кнопка перемещают камеру. Рамка выделения, перенос карточек и связи сохраняют прежнее назначение. Новый жест камеры отменяет незавершённый перенос карточки, восстанавливая её координаты. Камера не меняет сценарий, черновики или историю отмены. При переключении вида и resize сохраняется мировой центр доступной области; в скрытом виде камера ждёт возвращения доски. Fit автоматически выполняется только при первоначальном открытии.

Над превью работает его нативная прокрутка; над textarea — прокрутка текста. На границах scroll chaining ограничен. Локальное подавление pinch и Cmd/Ctrl + wheel охватывает `.app`, вынесенный в body `#shareModal` и будущие области с `data-preview-region`. Масштаб страницы через меню браузера остаётся доступным. Компенсации browser zoom через CSS нет.

У wheel нет стандартного идентификатора последовательности. При пересечении области непрерывный поток поглощается, пока не наступит пауза более 100 мс; клик или смена намерения обычная прокрутка/явный zoom также сбрасывает привязку. Это короткая эвристика, требующая проверки системной инерции на устройствах. Safari gesture закреплён за исходной областью; дубли wheel во время gesture и 80 мс после его окончания поглощаются. Отмена, Escape, blur, скрытие вкладки и потеря pointer capture сбрасывают состояния; для пропущенного gestureend есть страховочный таймаут 700 мс без событий. Это обработка настольного тачпада, а не новая реализация touchscreen pinch.

## Автоматические проверки

```sh
npm ci
npx playwright install chromium
npm test
node tools/check-navigation-browser.cjs
node tools/check-html-browser.cjs
```

Две последние проверки подают исходные ресурсы через Playwright routing, без HTTP-сервера. Для остальных браузерных проверок сначала запустите `node tools/preview.cjs`, затем `npm run test:browser`. Используются отдельные контексты браузера; пользовательское хранилище не очищается.

`check-navigation-unit.cjs` исполняет производственный обработчик в модели DOM/часов и отдельно проверяет геометрию камеры. `check-navigation-browser.cjs` проверяет wheel, нативную прокрутку, превью/диалоги/поля, переключение видов, неизменность сценария и новый автономный HTML. Отдельные проверки рамки, группового переноса и переподключения связей включены в `test:browser`. Ни dispatchEvent, ни Playwright mouse.wheel не являются проверкой физического тачпада.

Результат в ограниченной среде 3 ноября 2026:

- `npm test` и отдельные проверки HTML, безопасности/ZIP и неизменности сценариев прошли. HTML включает точные текущие версии app.js, board.js, board.css и editor-ui.js.
- Обязательные `check-board-browser`, `check-board-stress`, `check-shared`, а также новые проверки навигации, HTML и взаимодействия с карточками запускались, но браузер не стартовал: sandbox запрещает Chromium MachPortRendezvous (`Permission denied`). Сервер на 127.0.0.1:8000 также не стартовал (`EPERM`). Эти проверки не считаются пройденными.
- Установка закреплённого Playwright 1.64.1 недоступна из-за DNS npm. Для попыток запуска использован Playwright 1.63.0 из локального кэша, вне проекта; package.json и lockfile не менялись.
- Журналы попыток — `audit-max/navigation/`. Физические устройства не проверялись.

## Короткая ручная проверка

На macOS отдельно в Safari и Chromium, затем на Windows с precision touchpad в Chromium:

1. Открыть «Схема + превью». Двумя пальцами двигаться вертикально, горизонтально и диагонально: меняется камера, масштаб постоянен. Проверить обе системные настройки направления прокрутки.
2. Выполнить pinch над доской, полем и ботом; на macOS — Cmd + колесо, на Windows — Ctrl + колесо. Доска приближается вокруг указателя, бот и инструменты не меняют размер. Дойти до 8%/250% и сразу поменять направление. В Safari не должно быть двойного зума.
3. Прокрутить длинный чат, контакты, диалог телефона/оплаты и textarea до обоих краёв. Доска и документ остаются на месте. Раскрытый select и пробел при вводе работают нативно.
4. Проверить инерцию и переход через границу доска/превью; после короткой паузы следующее действие работает в новой области. Перенести карточку через границу, отменить Escape; потерять фокус во время Space-drag и pinch, вернуться — нет застрявших состояний.
5. При 25%, 100%, 250% проверить размер шрифта, кнопок, границы превью и позиции прокрутки. Переключить все три вида и изменить окно; мировой центр сохраняется. Проверить вертикальный переключатель: + сверху, процент посередине, − снизу; кнопок «100%» и «Вся схема» нет.
6. Мышью проверить обычное/горизонтальное колесо, Shift + колесо, среднюю кнопку, Space-drag, рамку, групповой перенос, создание/переподключение связи и отмену. Повторить основные жесты в свежескачанном HTML. Масштаб страницы через меню браузера остаётся работоспособным.

Firefox и Magic Mouse — дополнительная проверка при наличии устройств.
