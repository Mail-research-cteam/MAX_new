# Рабочая версия и границы изменений

Актуальная общая версия — `prototype/`. `prototype/index.html` — одна оболочка; `bot-lpr.html` и `bot-employee.html` — входные ссылки. `shared/app.js` содержит проигрыватель и карточки редактора; `shared/board.js` и `board.css` — управление доской; `shared/author.js` — варианты, черновики, импорт и ZIP. Данные находятся в `prototype/scenarios/`.

Корневые старые HTML и `audit-max/MAX-main/` — исходные материалы. Не переносите в них исправления автоматически. Не запускайте архивный `tools/build-shared.cjs`: генератор отключён, чтобы не перезаписать актуальную реализацию. Список ZIP обновляется командой `node tools/package-shared.cjs`.

## Добавление и изменение узлов

- Тексты, переходы, типы и задержки исследовательских сценариев менять только в рамках запроса. Правки координат не должны затрагивать эти поля.
- У существующих узлов сохранять конечные числовые `x` и `y`; не присваивать всем одинаковые координаты и не удалять ручную раскладку.
- Карточки имеют разную высоту: количество кнопок, контактов и изменение размера текстового поля влияют на фактические размеры. Проверка только JSON недостаточна.
- Новому узлу можно не задавать координаты: редактор поставит его через общий механизм `MaxBoard.place` с измерением карточки. Добавление/дублирование через редактор используют тот же механизм.
- Редактор автоматически разносит новые узлы, отсутствующие/некорректные координаты и точные дубликаты координат. Неполные наложения существующей ручной раскладки не исправляет молча: показывает число наложений и явную обратимую команду «Убрать наложения».
- После изменения большого текста или количества кнопок открыть сценарий с `?edit=1`, проверить индикатор наложений. При необходимости использовать «Убрать наложения», скачать JSON и перенести только координаты в файл. Не разносить всю схему при каждом вводе текста.
- Старый черновик может отличаться от файла. Не удалять localStorage молча. Проверять уведомление об изменённой базе, источник данных и команду «Файловая версия». Не объявлять файл проверенным по изображению старого черновика.

## Проверки

- `node tools/check-board-unit.cjs` — координаты, удаление конкретных выходов, размещение относительно высоких карточек.
- `node tools/check-board-browser.cjs` — ЛПР и сотрудник, мышь/клавиатура, панорамирование, удаление и отмена, размещение, черновик, экспорт.
- `node tools/check-board-stress.cjs` — три масштаба, отдельный искусственный сценарий из 130 карточек, длинный текст, конфликт данных файла и черновика.
- `node tools/check-shared.cjs` — базовые проверки общей основы, включая неизменность исходных сценариев.

Браузерные проверки требуют работающего `node tools/preview.cjs` на 8000 и используют отдельный профиль Edge. Фикстуры и результаты сохраняются в `tools/fixtures/` и `audit-max/`, не в рабочих сценариях. Физический трекпад тестами не проверяется: wheel-события моделируются. Не выдавайте моделирование за проверку на устройстве.
